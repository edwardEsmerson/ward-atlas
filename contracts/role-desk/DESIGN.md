# Frozen role-desk contract

One incident context per read, never a common shift or complete workload total.
Conveyor uses observed-event `as_of`; dock requires independent `effective_at`
and `known_at`. Roles are discovered only from full visible ownership paths.
Selection constrains the live graph query, not a constant index or oracle file.
Restoration removes active paths, retains ownership witnesses and cites the
observed event; no safety or resolution inference. Missing edges, unavailable
graph, crossed clocks and arbitrary/restricted/unestablished role IDs have the
same exact generic unknown body without input echoes or existence hints.

Discovery returns visible roles and exact source occurrences. Selection returns
only that role's path. Original roster 18:04/18:05 occurrences stay separate.
SOP claims never authorize owners. Strict singleton fields and malformed input
are rejected before graph reads. Native keyboard selection, responsive paths,
loading/error/unknown/restored states, escaped text and stale-response isolation
are required. No fixtures, models, contacts, scoring, clinical advice or writes.

Live checks own unique lane graph/state/processes, bootstrap the accepted pinned
FalkorDB module, accept explicit ports and overwrite only role-desk reports.
Expectations cite unchanged local oracle JSON pointers; no preparation packets
or other run evidence is read. Same-model testing is not an independent oracle.
